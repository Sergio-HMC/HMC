# Home Market Consulting — versión rediseñada

Proyecto Next.js existente actualizado con nueva portada, navegación, contacto sin formulario roto, páginas de residencia actualizadas, imágenes originales de Wix optimizadas y redirecciones antiguas.

## Publicación
Subir el contenido de esta carpeta a `HMC-site/` en la rama `main` del repositorio `Sergio-HMC/HMC`. Vercel desplegará automáticamente si continúa conectado a ese repositorio. No se han modificado GitHub, Vercel, Wix ni GoDaddy desde esta entrega.

## Pendientes antes de cancelar Wix
1. Comprobar la apariencia de las fotos originales elegidas para portada y bloque intermedio.
2. Probar todos los enlaces, especialmente WhatsApp, agenda y correo.
3. Revisar los contenidos de inversión y proyectos heredados; pueden incluir cifras o afirmaciones que requieren validación.
4. Verificar dominio personalizado, SSL y DNS de correo antes de cancelar Wix.
5. Confirmar condiciones de uso de Vercel Hobby para una web comercial: podría requerirse un plan de pago.

El formulario anterior no enviaba mensajes: se sustituyó por canales de contacto reales.
